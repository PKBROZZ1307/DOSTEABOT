# DOSTEA BOT

DOSTEA Bot is a customer support chatbot designed to enhance customer interactions and improve service efficiency. Developed as part of a second-year BTech project by a team of Artificial Intelligence & Data Science students, this bot leverages modern AI techniques to provide quick and accurate responses to customer queries.

## Features

- **Automated Customer Support**: Handles customer queries 24/7.
- **AI-Powered Responses**: Utilizes natural language processing for accurate understanding and replies.
- **Customizable Responses**: Tailor responses to fit your business needs.
- **Scalable Design**: Can handle a large number of concurrent users.
- **Easy Integration**: Compatible with various platforms (e.g., websites, apps).

## Installation

Follow these steps to set up DOSTEA Bot locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/PKBROZZ1307/DOSTEABOT.git
   ```

2. Navigate to the project directory:

   ```bash
   cd DOSTEABOT
   ```

3. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Start the bot:

   ```bash
   python main.py
   ```

## Usage

1. Ensure that the server is running.
